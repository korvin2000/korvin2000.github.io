# Политика конфиденциальности

Приложение «Аудиокниги» не собирает персональные данные и не передаёт их разработчику или третьим лицам.

Если пользователь сам подключает облачную синхронизацию, приложение хранит файл синхронизации (избранные книги, история прослушивания, избранные авторы и чтецы, позиции прослушивания, настройки приложения) в облаке этого пользователя: на Google Диске — только в скрытой папке приложения (разрешение drive.appdata), на Яндекс Диске — только в папке приложения (cloud_api:disk.app_folder). К остальным файлам пользователя приложение доступа не получает.

Данные передаются напрямую между устройством и облаком пользователя. Токены доступа хранятся только на устройстве. Синхронизацию можно выключить в настройках приложения, доступ можно отозвать в настройках аккаунта Google или Яндекса, файл синхронизации можно удалить в своём облаке.

Использование и передача приложением информации, полученной от API Google, соответствует [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use.
