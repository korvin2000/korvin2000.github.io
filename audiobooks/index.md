# Аудиокниги

Android-приложение для прослушивания аудиокниг с открытых сайтов-каталогов.

По желанию пользователя избранное, история, позиции прослушивания и настройки синхронизируются между его устройствами через его собственный Google Диск или Яндекс Диск.
